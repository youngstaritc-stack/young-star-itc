## Codespace

From the repository root:

```bash
cd /workspaces/young-star-itc
git pull --ff-only origin main
python -m http.server 4173 --directory ui_preview
```

Then open the forwarded port **4173** in Codespaces. The preview contains Splash, Login, Dashboard, Live Market, Analysis, and Profile references.

The preview is visual-only. It does not change the Rule Book logic or Parts 1–7 engine behavior.
